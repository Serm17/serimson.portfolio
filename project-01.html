Project 01

Can AI find the right Product?

여행상품 페이지 GEO 개선 실험 · 상품은 존재하지만 AI 추천에서 누락되는 이유를 찾다.

Problem

실험 대상 상품은 날짜·가격·일정 조건을 충족했지만 AI 추천에서 누락되었습니다. 따라서 “정보가 있는데도 AI는 왜 상품을 찾지 못했을까?”를 핵심 질문으로 두었습니다.

Finding

01

상품 Entity가 약함

브랜드 중심 title로 개별 상품의 정체성이 약했습니다.

02

핵심 조건 관계가 약함

날짜와 가격은 존재하지만 상품과의 관계를 명확히 읽기 어려웠습니다.

03

중요 정보가 분산됨

일정·포함사항·선택관광·예약 상태가 서로 다른 영역에 흩어져 있었습니다.

Optimization Priority

새로운 콘텐츠를 추가하기보다 기존 정보를 AI가 이해하기 쉬운 구조로 정리하는 것을 먼저 선택했습니다. 상품 Entity 명확화와 핵심 조건 구조화를 P1, Structured Data를 P2, 추가 콘텐츠 제작을 P3로 두었습니다.

Validation

재측정이 완료되지 않은 항목은 임의 수치로 채우지 않습니다. 현재 상태 확인 → 개선안 적용 → 같은 조건으로 재실험 → 개선 전후 비교의 순서로 검증합니다. LLM 응답 변동성, 검색 반영 시점, 플랫폼별 검색 방식, 실제 구매 전환의 별도 측정 필요성은 실험의 한계로 남깁니다.
