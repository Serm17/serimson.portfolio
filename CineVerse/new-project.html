01 · OVERVIEW프로젝트 소개

사용자 맞춤형 AI 서비스를 위해 필요한 Memory 정책과 Retrieval 기준을 설계하는 프로젝트입니다.

사용자와의 대화에서 어떤 정보를 기억해야 하는지, 과거 기억과 최근 정보가 충돌할 때 무엇을 우선해야 하는지, 그리고 외부 검색이나 RAG 없이 저장된 사용자 맥락만으로 얼마나 자연스럽고 일관된 대화가 가능한지를 실험합니다.

이를 통해 기억의 저장·조회·갱신·삭제 기준과 RAG 사용 조건을 정의하고, 실제 대화 품질에 어떤 영향을 주는지 검증합니다.

02 · DISCOVERY문제의 출발점

CineVerse에서 사용자 맞춤 추천을 제공하려면, 사용자의 취향과 이전 대화 맥락을 기억하는 기능이 필요했습니다.

하지만 모든 대화를 그대로 기억하는 방식은 비효율적이고, 오래된 기억이 최근 정보와 충돌할 경우 어떤 정보를 우선해야 하는지도 명확한 기준이 필요했습니다.

또한 캐릭터와의 대화에서 외부 검색이나 RAG에 의존하지 않고, 저장된 사용자 맥락만으로 얼마나 자연스럽고 일관된 질의응답이 가능한지도 확인하고 싶었습니다.

그래서 이번 프로젝트에서는 무엇을 기억할지, 언제 기억을 갱신하거나 버릴지, 그리고 언제 RAG를 사용해야 하는지에 대한 AI Memory 정책을 설계하고 검증하고자 했습니다.

03 · HYPOTHESIS가설

사용자 맞춤형 AI에서는 많은 정보를 기억하는 것보다, 현재 대화에 필요한 기억을 정확하게 사용하는 것이 더 중요하다고 판단했습니다.

또한 사용자 정보는 시간이 지나며 바뀔 수 있기 때문에, 과거 기억을 그대로 유지하는 방식만으로는 자연스러운 개인화가 어렵습니다.
따라서 기억의 저장·갱신·충돌 처리 기준과, Memory만으로 답할지 RAG를 사용할지에 대한 정책이 필요합니다.
