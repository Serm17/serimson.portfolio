GEO / AI Search

사용자의 질문에서 무엇이 발견되지 않는지 정의하고, AI가 정보를 어떻게 이해·추천·인용하는지 측정 가능한 실험으로 검증합니다.

Portfolio updated · 2026.09.17

어떤 문제를 다루는가

GEO를 단순 노출 최적화가 아니라 ‘적절한 질문에서 적절한 선택지로 등장할 수 있는 정보 구조를 만드는 일’로 보고 있습니다.

그래서 새로운 콘텐츠를 무작정 늘리기보다, 사용자 질문을 분해하고 실제 페이지의 Entity·조건·근거가 AI에게 어떻게 연결되는지 확인합니다.

일하는 방식

01

Define

사용자가 원하는 결과와 AI가 놓치는 지점을 먼저 정의합니다.

02

Measure

같은 Query Set과 조건으로 반복 측정해 비교 가능한 기준을 만듭니다.

03

Improve

영향도와 구현 비용을 기준으로 정보 구조의 우선순위를 정합니다.

04

Re-test

같은 조건으로 다시 테스트해 실제 변화를 확인합니다.
