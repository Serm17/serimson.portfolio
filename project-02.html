Live experiment · sonserim.me.kr · Updated 2026.09.17

Goal

이 사이트가 발견되고, ‘손세림 ↔ GEO / AI Search’가 연결되고, 관련 질문의 근거로 실제 페이지가 인용되는지를 검증합니다.

단순히 사이트를 만드는 데서 끝내지 않고, 공개 후 동일 Query Set으로 결과를 누적하는 진행형 GEO 실험입니다.

현재 검색 측정 결과

2026.09.17브랜드 검색 노출 확인

Google에서 ‘손세림 GEO’, ‘손세림 AI Search’ 검색 시 포트폴리오 노출을 확인했습니다. 반면 이름이 없는 비브랜드 검색어 ‘GEO 포트폴리오’에서는 아직 노출되지 않았습니다.

현재는 손세림 ↔ GEO / AI Search 연결은 확인했지만, 일반 카테고리 검색에서의 발견성은 다음 개선 과제로 남아 있습니다. 그래서 title·H1·첫 문단·내부 링크와 GEO 포트폴리오 전용 허브 페이지를 보강한 뒤 동일 쿼리로 다시 측정합니다.

GEO를 위해 사이트에 적용한 구조

01

Entity

손세림 → GEO / AI Search → Project 관계를 페이지 본문과 구조화 데이터에서 일관되게 표현합니다.

02

Dedicated URLs

About, Good GEO, GEO Measurement, Project 01, Project 02에 각각 독립 URL을 제공합니다.

03

First-party Content

Good GEO 정의, 측정 프레임워크, 실험 과정과 한계를 직접 작성해 검색·AI가 인용할 수 있는 1차 정보를 제공합니다.

04

Machine Readability

Semantic HTML, canonical, sitemap, JSON-LD, descriptive title/description, 내부 링크를 사용합니다.

05

Crawler Access

robots.txt에서 일반 크롤러와 OAI-SearchBot 접근을 허용하고 sitemap을 명시합니다.

03

Good GEO 정의와 프로젝트 핵심 내용이 정확하게 반영되는가?

기술적 발견성

Google AI 기능은 별도의 ‘GEO 전용 태그’를 요구하지 않기 때문에, 기본적인 검색 색인 가능성과 명확한 텍스트·내부 링크·구조화 데이터를 우선합니다. ChatGPT 검색 노출을 위해서는 OAI-SearchBot을 차단하지 않습니다. Bing 계열의 빠른 변경 알림을 위해 sitemap과 IndexNow 제출 도구도 함께 준비합니다.
